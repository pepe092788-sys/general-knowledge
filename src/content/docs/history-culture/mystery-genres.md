ミステリーと聞くと、探偵が犯人を突き止める物語を思い浮かべるかもしれません。しかし、最初から犯人が分かっている作品もあれば、犯罪が起こらない作品もあります。

法律を題材としたリーガルミステリーや、科学的な知識を使って謎を解く作品もあります。これらは何を基準に分類されているのでしょうか。

## 何を解き明かすのか

ミステリーの謎には、代表的な三つの切り口があります。

| 用語 | 中心となる疑問 | 面白さ |
| --- | --- | --- |
| フーダニット（Whodunit） | 誰が犯人なのか | 手掛かりから犯人を特定する |
| ハウダニット（Howdunit） | どうやって事件が起きたのか | 不可能に見える出来事の仕組みを解明する |
| ホワイダニット（Whydunit） | なぜ事件が起きたのか | 動機や人間関係、背景を理解する |

例えば、鍵のかかった部屋で事件が起きたという架空の物語を考えてみます。犯人の正体を探すならフーダニット、不可解な状況の仕組みを解明するならハウダニット、事件に至った事情を探るならホワイダニットです。

一つの作品が三つの謎を同時に扱うこともあります。また、犯罪を伴わない謎も存在するため、ミステリーのすべてをこの三分類だけで説明できるわけではありません。

## 謎解きと物語の構成

| 種類・手法 | 特徴 |
| --- | --- |
| 本格ミステリー | 手掛かりや論理を重視し、事件の真相に迫る |
| 新本格ミステリー | 日本では1980年代後半以降の、本格推理小説を再活性化した潮流を指すことが多い |
| 倒叙ミステリー | 犯人や犯行が先に示され、探偵がどう真相にたどり着くかを楽しむ |
| 日常の謎 | 日常生活の中にある不可解な出来事を解き明かす |
| 叙述トリック | 語り方や情報の提示によって読者の認識を誘導する技法 |
| 安楽椅子探偵もの | 主に他者から得た情報をもとに、現場へ出向かず推理する探偵を描く |

本格ミステリーは作品の方向性、倒叙は物語の構成、叙述トリックは表現技法です。これらは同じ基準による分類ではありません。

倒叙ミステリーでは、読者が犯人を知っていても、探偵が何に気づくのか、どう真相を証明するのかという別の疑問が生まれます。謎をすべて隠すことだけがミステリーの面白さではないのです。

## 職業や専門知識による分類

| 種類 | 特徴 |
| --- | --- |
| 警察ミステリー | 警察の捜査や組織的な事件解決を描く |
| リーガルミステリー | 法律、裁判、証拠、司法制度を通じて真相を追究する |
| 医療ミステリー | 医学的知識や医療現場の出来事を題材とする |
| 科学ミステリー | 科学的知識や実験が謎の解明に関わる |
| 経済ミステリー | 企業活動、金融取引、経済犯罪などを題材とする |

例えばリーガルミステリーでは、事件の真相を知ることと、その事実を裁判で証明することは必ずしも同じではありません。

法律に従うことと正義を実現することは一致するのか、証拠からどこまで事実を認定できるのかといった問題も、物語の重要な要素になります。

科学ミステリーでは自然現象や技術の理解が、経済ミステリーでは企業や資金の仕組みの理解が、謎解きにつながることがあります。物語を通じて、特定の分野に興味を持つきっかけにもなります。

## 人間や社会、読後感による分類

| 種類 | 特徴 |
| --- | --- |
| 社会派ミステリー | 犯罪の背景にある社会問題や制度、人間関係を掘り下げる |
| 心理ミステリー | 登場人物の心理、動機、葛藤などに重点を置く |
| ハードボイルド | 抑制された語り口や主人公の生き方、社会の暗部などを特徴とする |
| イヤミス | 人間の悪意や醜さなどを描き、割り切れない読後感を残す |
| コージーミステリー | 身近な共同体や人間関係を舞台に、過度に生々しい暴力描写を避ける傾向がある |
| リーガルサスペンス | 司法や法律をめぐる対立、危機、緊張感に重点を置く |

本格ミステリーが論理的な解明を重視するのに対し、社会派ミステリーでは事件が生まれた背景そのものが中心的な関心になることがあります。ただし、論理的な謎解きと社会的なテーマは両立します。

## 舞台や世界のルールによる分類

| 種類・設定 | 特徴 |
| --- | --- |
| 歴史ミステリー | 過去の時代や歴史上の出来事を題材とする |
| SFミステリー | 科学技術や未来社会などの仮定を取り入れる |
| ファンタジーミステリー | 魔法や架空世界の法則を前提に謎を描く |
| オカルトミステリー | 怪奇現象や超常現象を題材とする |
| 特殊設定ミステリー | 現実とは異なる条件や特殊なルールを謎解きに利用する |
| クローズドサークル | 孤島や雪山など、外部との行き来が難しい環境を舞台とする |

特殊設定ミステリーでは、現実には存在しない能力や現象が登場しても、その世界のルールに従って論理的に謎を解くことができます。

クローズドサークルは舞台設定であり、本格ミステリーや特殊設定ミステリーと組み合わせることもできます。

## 作品から分類を理解する

以下は作品の特徴を理解するための例です。結末や具体的な仕掛けには触れません。

| 作品 | 分類の例 |
| --- | --- |
| 綾辻行人『十角館の殺人』 | 新本格、クローズドサークル |
| 『刑事コロンボ』（ドラマ） | 倒叙、警察ミステリー |
| 米澤穂信『氷菓』 | 日常の謎 |
| 『逆転裁判』（ゲーム） | リーガルミステリー |
| 東野圭吾のガリレオシリーズ | 科学ミステリー |
| 松本清張『砂の器』 | 社会派ミステリー |
| 湊かなえ『告白』 | 心理ミステリー、イヤミス |
| 今村昌弘『屍人荘の殺人』 | 特殊設定、本格ミステリー |

これらは唯一の正しい分類ではなく、作品の特徴を表すための例です。叙述トリックのように、分類を知ること自体が読書体験に影響する技法については、あえて作品例を挙げていません。

## なぜ分類が重なるのか

ミステリーの分類には、統一された唯一の体系があるわけではありません。

何を解くのか、どのように物語を進めるのか、どんな世界で起こるのか、どんな読後感をもたらすのかという、それぞれ異なる視点があります。

例えば、孤島を舞台とした本格ミステリーで、法律の知識を使って動機を解明する作品を想像すれば、クローズドサークル、リーガル、本格、ホワイダニットという複数の特徴を併せ持つことが分かります。

## 今日のなるほど

ミステリーは、単に犯人を探す物語ではありません。分からなかった出来事の理由や背景が明らかになる過程を楽しむ物語でもあります。

ジャンル名は作品を一つの箱に収めるためだけではなく、**その物語がどんな謎や面白さを提供するのかを知る手掛かり**なのです。
