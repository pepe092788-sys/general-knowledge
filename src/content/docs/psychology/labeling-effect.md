「あの人は仕事ができない」「あの子は勉強が得意だ」。

私たちは日常的に、他者の特徴を短い言葉で表現しています。しかし、その言葉は単に相手の特徴を説明しているだけなのでしょうか。

ある人に対する評価が、周囲の接し方を変え、その人が経験する環境まで変えてしまうことがあります。

## ラベリング効果とは

人に対して付けられた評価や分類（ラベル）が、その人に対する周囲の認識や、本人の自己認識・行動に影響する現象を、ここではラベリング効果と呼びます。

この言葉は幅広い意味で使われます。社会学のラベリング理論や社会心理学の自己成就予言など、関連する複数の概念を区別しながら理解すると、その仕組みが見えてきます。

例えば、子どもが「勉強が得意な子」と認識されることで、周囲から学習の機会を多く与えられ、本人も積極的に学ぶようになることがあります。

反対に、「何をやっても続かない人」という評価を繰り返し受けることで、本人が自信を失い、新しい挑戦を避けるようになる可能性もあります。

## 評価が現実を変える仕組み

職場で、ある社員が一度の失敗をきっかけに「仕事ができない人」と評価されたとします。

1. 上司や同僚が、その社員の能力を低く見積もる。
2. 重要な仕事を任せたり、指導したりする機会が減る。
3. 本人が経験を積む機会や自信を得る機会が減る。
4. 能力を発揮したり、新しい成果を示したりする機会が少なくなる。
5. 周囲が「やはり仕事ができない」と判断する。

これは起こり得る悪循環の一例です。

ここで注目したいのは、最初の評価が正しかったかどうかとは別に、その評価に基づく接し方が、後の結果に影響していることです。

ある予想や思い込みによって行動が変わり、その結果が予想を現実に近づける現象は、自己成就予言と呼ばれます。社会心理学では、相手に対する期待が相互作用を通じて相手の行動を変える「行動的確証」についても研究されています。

もちろん、人が必ずラベルのとおりになるわけではありません。本人の経験、周囲からの支援、置かれた環境など、多くの要因が関係します。

## 同じ行動でも見え方が変わる

ラベルは本人の行動だけでなく、周囲がその行動をどう解釈するかにも関係します。

| 行動 | 肯定的な解釈の例 | 否定的な解釈の例 |
| --- | --- | --- |
| 意見を変えない | 信念がある | 頑固 |
| 積極的に発言する | 主体性がある | 出しゃばり |
| 判断に時間をかける | 慎重 | 優柔不断 |
| 細かな部分を確認する | 丁寧 | 神経質 |
| 一人で仕事を進める | 自立している | 協調性がない |

この表は、同じ行動が常に等しく評価されるべきだという意味ではありません。状況や目的によって、実際に適切な評価は変わります。

ただし、あらかじめ抱いている人物像が、どの情報に注目し、どう解釈するかに影響することがあります。

例えば、既に「不注意な人」と認識している相手の失敗には敏感になり、成功にはあまり注目しなくなるかもしれません。このような情報の選び方には、確証バイアスという別の心理現象が関係します。

## 学問的な背景：ラベリング理論

社会学にはラベリング理論という考え方があります。ハワード・ベッカーの著書『アウトサイダーズ』（1963年）などを通じて広く知られるようになりました。

この理論では、社会の規範から外れた行為や人に対して周囲がどのような意味を与え、その社会的な反応が本人の立場やその後の行動にどう関係するかを考えます。

例えば、ある行為をした人が社会から逸脱者として扱われることで、他の人との関係や社会参加の機会が変化する可能性があります。

ラベリング理論は、すべての逸脱行動が周囲の評価だけで生じると説明するものではありません。行為そのものに加え、社会がその行為にどう反応するかに注目する視点です。

## 関連する心理学の概念

| 用語 | 注目する仕組み |
| --- | --- |
| ラベリング効果 | 評価や分類が認識・接し方・行動に与える影響 |
| 自己成就予言 | 予想に基づく行動が、予想した結果を生じさせること |
| ピグマリオン効果 | 他者の高い期待が成果の向上につながることがある現象 |
| ゴーレム効果 | 他者の低い期待が成果の低下につながることがある現象 |
| 確証バイアス | 既存の考えを支持する情報を重視しやすい傾向 |
| ハロー効果 | ある特徴や全体的な印象が別の特徴の評価にも影響すること |

これらは同じ現象の別名ではありません。しかし、人への評価がどのように形成され、維持され、現実の行動に影響し得るのかを理解するうえで、互いに関係しています。

## 人材育成において、何を評価するのか

ある社員が確認不足によるミスをしたとします。

「あなたは注意力がない」と伝える場合と、「今回の作業では確認が不足していた」と伝える場合では、評価している対象が異なります。

前者は人の性質を評価し、後者は具体的な行動を評価しています。

具体的な行動について話すと、どの工程で確認が不足したのか、どのような仕組みがあれば防げるのか、改善した結果をどう確認するのかという議論につなげやすくなります。

一方、人物全体への評価を固定してしまうと、その後の成長や状況の変化を見落とす可能性があります。

肯定的なラベルであっても、「得意な人だから失敗してはいけない」という重圧になる場合があります。逆に、適切な分類が必要な支援や相互理解につながることもあります。

ラベルを使うこと自体が問題なのではなく、限られた情報から人物像を固定し、その評価を見直さなくなることに注意が必要です。

## 今日のなるほど

人への評価は、その時点での状態を表すだけでなく、周囲の接し方や本人の経験を通じて、その後の行動に影響することがあります。

人を理解するために付けたはずのラベルが、その人を理解する妨げになることもあるのです。

**観察された行動と、人そのものへの評価を区別すること。そして、新しい事実が得られたときには評価を見直すこと。** ラベリング効果は、人間を評価することの難しさを考える手掛かりになります。
