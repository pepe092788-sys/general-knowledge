株式や投資信託の価格は、日々変動しています。

同じ商品を購入するのであれば、できるだけ安いときに購入したいものです。しかし、今の価格が高いのか安いのか、これからさらに下がるのかを事前に判断することは容易ではありません。

そこで、価格に応じて購入するタイミングを変えるのではなく、購入する金額を一定にするという考え方があります。

これがドルコスト平均法です。

## ドルコスト平均法とは

ドルコスト平均法（Dollar Cost Averaging）とは、価格が変動する金融商品を、定期的に一定の金額で購入する方法です。定額購入法とも呼ばれます。

例えば、毎月6,000円分の金融商品を購入すると決めた場合、価格が上がっても下がっても、購入する金額は変えません。

ここで重要なのは、一定にするのが購入する「数量」ではなく「金額」であることです。

- 価格が高いときは、少ない数量を購入する。
- 価格が安いときは、多くの数量を購入する。

価格の変動に応じて、購入する数量が自然に変化する仕組みです。

なお、名称に「ドル」とありますが、米ドルで投資する必要はなく、日本円でも同じ考え方が成立します。

## 一定額と一定数量の違い

実際に数字を使って、その仕組みを確認してみましょう。

ある金融商品の価格が、3ヶ月間で1,000円、500円、1,500円と変動したとします。

### 毎月6株ずつ購入する場合

| 購入時期 | 1株の価格 | 購入数量 | 購入金額 |
| --- | ---: | ---: | ---: |
| 1月 | 1,000円 | 6株 | 6,000円 |
| 2月 | 500円 | 6株 | 3,000円 |
| 3月 | 1,500円 | 6株 | 9,000円 |
| 合計 | ― | 18株 | 18,000円 |

1株あたりの平均取得単価は1,000円です。

### 毎月6,000円ずつ購入する場合

| 購入時期 | 1株の価格 | 購入数量 | 購入金額 |
| --- | ---: | ---: | ---: |
| 1月 | 1,000円 | 6株 | 6,000円 |
| 2月 | 500円 | 12株 | 6,000円 |
| 3月 | 1,500円 | 4株 | 6,000円 |
| 合計 | ― | 22株 | 18,000円 |

1株あたりの平均取得単価は約818円です。

どちらも18,000円を使っていますが、購入できた株数には違いが生まれました。

※手数料などを考慮せず、任意の数量を購入できると仮定した例です。

## なぜ平均取得単価が低くなるのか

毎回同じ数量を購入すると、価格が高いときも安いときも、保有する株式に占める割合は同じになります。

一方、毎回同じ金額を購入すると、安いときに購入した株式の割合が大きくなります。

その結果、平均取得単価を計算したときに、安い価格の影響をより強く受けることになります。

数学的には、同じ数量を購入した場合の平均取得単価は「算術平均」、同じ金額を購入した場合は「調和平均」に相当します。

手数料や購入単位による端数などを考慮せず、同じ時期に同じ商品を正の価格で購入する条件では、定額購入の平均取得単価が定量購入の平均取得単価を上回ることはありません。

つまり、この違いは偶然ではなく、数学的な仕組みによって生まれています。

## 購入するタイミングを分散する

まとまった資金を一度に投資すると、その時点の価格が取得単価になります。

購入直後に価格が大きく下落した場合、投資した資金全体がその影響を受けます。

ドルコスト平均法では、購入する時期を複数に分けるため、特定の時点の価格に購入結果が左右されにくくなります。

これを時間分散と呼びます。

安い時期を正確に予測するのではなく、異なる価格で購入する機会を設けるという考え方です。

## 必ず利益が出るわけではない

ドルコスト平均法は、購入方法に関する仕組みであり、投資対象の価格を上昇させる仕組みではありません。

例えば、平均取得単価が約818円になったとしても、その後の株価が600円になれば、保有資産の評価額は購入金額を下回ります。

反対に、価格が上昇し続ける場合には、最初にまとまった資金を用意できていれば、一度に購入した方が多くの利益を得られることもあります。

定額購入と定量購入を比較したときの数学的な特徴と、一括購入を含めた投資全体の収益性は、別の問題です。

ドルコスト平均法は、利益や元本を保証するものではありません。

## 長期・積立・分散はそれぞれ異なる概念

資産形成について調べていると、「長期・積立・分散」という言葉を目にすることがあります。

これらは組み合わせて利用されることが多いものの、それぞれ異なる考え方です。

| 概念 | 内容 |
| --- | --- |
| 長期投資 | 長い期間にわたって資産を保有する |
| 積立投資 | 資金を複数回に分けて投資する |
| 分散投資 | 投資対象や地域、購入時期などを分散する |

ドルコスト平均法は、一定額で行う積立投資の方法であり、購入時期を分散する仕組みでもあります。

ただし、一つの企業の株式だけを定期的に購入しても、投資対象そのものが分散されるわけではありません。

## 今日のなるほど

価格が変動する商品を購入するとき、何を一定にするかによって、平均取得単価の計算結果は変わります。

購入数量ではなく購入金額を一定にすることで、安いときには多く、高いときには少なく購入することになる。

ドルコスト平均法とは、価格の変動に応じて購入数量を変化させる、数学的な仕組みを利用した購入方法なのです。
