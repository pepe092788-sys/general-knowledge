給与を受け取るときも、住宅の家賃を支払うときも、通常は消費税がかかりません。しかし、消費税の制度上、この二つは異なる扱いを受けます。

給与は「不課税」、一定の条件を満たす住宅の家賃は「非課税」です。

どちらも消費税がかからないのに、なぜわざわざ区別しているのでしょうか。

## そもそも消費税は何にかかるのか

消費税は、商品の購入やサービスの利用などを通じて、消費に負担を求める税金です。

国内の一般的な取引については、次の四つの要件から課税の対象となるかを考えます。

- 国内で行われる取引であること。
- 事業者が事業として行うこと。
- 対価を得て行うこと。
- 資産の譲渡・貸付け、またはサービスの提供であること。

例えば、お店でパソコンを購入する場合、お店は事業として商品を販売し、購入者から代金を受け取ります。国内で行われるこの取引は、原則として課税の対象になります。

ただし、輸入取引や特定の国外事業者からのサービスの仕入れ、一定のみなし譲渡などには別の規定があります。ここでは国内の一般的な取引を中心に説明します。

## 不課税とは

不課税とは、消費税の課税対象にそもそも該当しないことです。課税対象外とも呼ばれます。

例えば、従業員が雇用契約に基づいて受け取る給与は、独立した事業者として提供するサービスの対価ではないため、消費税の課税対象にはなりません。

見返りのない寄附金も、商品やサービスの対価ではありません。そのため不課税となります。

お金が動いたという事実だけで、消費税の対象になるわけではないのです。

## 非課税とは

非課税とは、通常の課税要件を満たす取引の中で、消費税法が課税しないと定めているものです。

例えば、事業者が国内で土地を販売する取引は、対価を得て行う資産の譲渡です。しかし、土地の譲渡は法律によって非課税とされています。

非課税取引が設けられている主な理由は、消費に対する税という性質になじまないことや、社会政策上の配慮です。

土地や一定の金融取引は前者の例です。保険診療や一定の住宅の貸付けは後者の例です。

したがって、非課税は単に「税金を払わなくてよい」という意味ではなく、法律が定めた取引の区分なのです。

## 具体例で比較する

| 取引の例 | 消費税の区分 |
| --- | --- |
| 店舗でのパソコンの販売 | 課税 |
| 飲食店での食事の提供 | 課税 |
| 事業として行う土地の譲渡 | 非課税 |
| 一定の条件を満たす住宅の貸付け | 非課税 |
| 公的医療保険に基づく診療 | 非課税 |
| 預貯金の利子 | 非課税 |
| 事業として行う株式の譲渡 | 非課税 |
| 雇用契約に基づく給与・賃金 | 不課税 |
| 対価性のない寄附金 | 不課税 |
| 株式の配当金 | 不課税 |

株式に関する取引でも、株式の譲渡と配当金では消費税の区分が異なります。

また、住宅の家賃と事務所の家賃では取扱いが異なります。単に「家賃」という名前だけで判断するのではなく、取引の内容と条件を確認することが大切です。

なお、ここでいう非課税・不課税は消費税についての区分です。所得税や法人税など、ほかの税金までかからないという意味ではありません。

## 免税とは何が違うのか

消費税がかからない取引には、輸出免税という仕組みもあります。

例えば、事業者が商品を海外へ輸出する場合、一定の要件と証明書類の保存などを満たせば、輸出取引に対する消費税が免除されます。国外で消費される商品に日本の消費税を負担させないための仕組みです。

| 区分 | 消費税がかからない理由 |
| --- | --- |
| 不課税 | 課税の対象に該当しない |
| 非課税 | 法律が非課税取引として定めている |
| 輸出免税 | 課税取引について一定の要件により税が免除される |

なお、事業者の納税義務が免除される「免税事業者」は、取引そのものの区分とは別の概念です。

## なぜ経理で区別する必要があるのか

消費税がかからないという結果だけを見れば、非課税も不課税も同じように思えます。

しかし、事業者が仕入れや経費に含まれる消費税を売上に係る消費税から差し引く仕入税額控除を計算する際には、取引の区分が重要になります。

例えば、課税売上割合の計算では、非課税売上は原則として分母に含まれますが、不課税取引は含まれません。輸出免税売上は原則として分子と分母の両方に含まれます。

実際には有価証券の譲渡などに特別な計算規定もあります。具体的な納税額は取引の内容や適用する計算方法によって異なります。

税額がゼロであることと、税制度上どの区分に属するかは、別の問題なのです。

## どこで調べれば分かるのか

具体的な取引について調べるときは、まず国税庁の「タックスアンサー」を確認すると、基本的な判断基準と代表例を把握できます。

判断するときは、まず課税対象に該当するかを確認し、そのうえで非課税や免税などの規定が適用されるかを調べます。

この順序を理解していれば、初めて目にする取引でも、何を調べればよいのかが分かります。

## 今日のなるほど

非課税と不課税は、消費税がかからないという点では同じです。しかし、不課税は課税対象の外にある取引であり、非課税は法律によって課税しないことが定められた取引です。

**税金がかからないという結果ではなく、その理由によって区分が決まります。**

本記事は日本の消費税制度の基本的な理解を目的としています。制度や取引条件に応じた例外があるため、実際の申告や経理処理では最新の法令・国税庁資料を確認し、必要に応じて税務署や税理士に相談してください。
