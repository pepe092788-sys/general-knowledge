商品が11月30日に届き、12月2日に検収され、12月5日に請求書が届いたとします。この取引は何月の取引なのでしょうか。

物流の視点では11月に届いた商品ですが、契約上の受入確認は12月です。さらに、会計上いつ認識するべきかは、取引の実態や適用する会計基準によって判断する必要があります。

一つの取引にいくつもの日付が存在するのは、それぞれ異なる事実を表しているからです。

## 発注から支払までの日付

| 用語 | 意味 | 経理実務上のポイント |
| --- | --- | --- |
| 発注日 | 商品やサービスを注文した日 | 予算・発注残の管理。通常、発注のみで仕入や費用を認識しない |
| 出荷日 | 売り手が商品を発送した日 | 売上認識や輸送中の商品を把握する手掛かり |
| 納品日 | 売り手が商品や成果物を納めた日 | 納品書と実際の納品内容を照合する |
| 受領日 | 買い手が商品や成果物を受け取った日 | 仕入・在庫の確認や法令上の支払期限の管理 |
| 入庫日 | 商品を倉庫などに入庫した日 | 現物在庫と帳簿上の在庫を照合する |
| 検品日 | 数量、品質、破損などを確認した日 | 不足や不良品を把握し、返品・請求調整につなげる |
| 検収日 | 契約に従って納品物を確認し、受入れを認めた日 | 契約の履行確認や支払承認の根拠 |
| 計上日 | 売上、仕入、費用、資産などを会計上認識する日 | 正しい会計期間に取引を帰属させる |
| 請求日 | 売り手が代金を請求した日 | 請求内容と債権・債務の照合 |
| 支払期日 | 代金を支払うべき期限 | 契約・法令の遵守と資金繰り |
| 支払日 | 実際に代金を支払った日 | 買掛金などの消込み、二重払いの防止 |

納品日と受領日は同じ日になることが多いものの、売り手と買い手で記録の基準が異なる場合もあります。各社の用語や業務ルールは契約や社内規程で確認します。

## 受領と検収は何が違うのか

受領は商品や成果物を受け取ることです。検品は数量や状態などを確認すること、検収は契約上の条件を満たしているかを確認して受入れを判断することです。企業によっては検品と検収を一つの手続として扱う場合もあります。

例えば、システム開発でプログラムを受け取っただけでは、要求仕様どおりに動作するとは限りません。テストを実施し、契約で定めた受入条件を満たすかを確認して、検収するという流れが考えられます。

受領日と検収日を記録することで、未検収の納品物や検収にかかった期間も把握できます。

## 受領日と支払期限

支払期限の起算日が検収日であるとは限りません。

2026年1月施行の中小受託取引適正化法（取適法、旧下請法）の対象取引では、検査をするかどうかにかかわらず、原則として給付を受領した日（役務提供委託では役務が提供された日）を起算日として、60日以内のできる限り短い期間に支払期日を定める必要があります。

検収に時間がかかることを理由に、法定の支払期限を自由に延長できるわけではありません。対象となる委託取引や例外、起算日の詳細は公正取引委員会の資料を確認してください。

## 検収と三点照合

経理担当者がすべての納品物の品質を直接確認することは難しいため、購買・受入部門の記録を利用します。

発注書、受領・入庫記録などの受入実績、請求書を照合する方法は三点照合（Three-way matching）と呼ばれます。契約や運用に応じて検収記録も確認します。

| 照合する資料 | 確認する内容 |
| --- | --- |
| 発注書 | 注文した品目・数量・単価 |
| 受領・入庫記録、必要に応じて検収記録 | 実際に受け取った数量や受入状況 |
| 請求書 | 請求された数量・単価・金額 |

例えば100個を発注したのに90個しか届いておらず、100個分の請求が来た場合、分納や不足の扱いを確認します。契約上の支払条件も踏まえて差異を解消します。

この照合は、過剰請求、二重請求、未納品への誤払いを防ぐための内部統制の一つです。

## 計上日はどのように決まるのか

計上日は、商品の移動や請求書の発行そのものの日付ではなく、会計上の取引を認識する日です。会計システムに入力した登録日時とは区別します。

売り手の売上認識について、企業会計基準の収益認識の考え方では、約束した財やサービスを顧客に移転し、履行義務を充足した時点または期間にわたって収益を認識します。

出荷時、着荷時、検収時はその判断に関係する時点ですが、単に都合のよい日を選べるわけではありません。国内の商品・製品販売では、出荷から支配の移転までが通常の期間である場合に、出荷時や着荷時などで収益を認識できる代替的な取扱いもあります。

また、検収が形式的な確認にすぎない場合と、実質的な受入条件になっている場合では判断が異なることがあります。

買い手についても、資産や負債、費用の認識は取引の実態と適用する会計方針に基づいて判断します。売り手の収益認識の規定をそのまま買い手の仕入認識に当てはめるものではありません。

## 月をまたぐ取引とカットオフ

冒頭の取引をもう一度確認してみましょう。

| 日付 | 出来事 |
| --- | --- |
| 11月30日 | 商品を納品・受領 |
| 12月2日 | 検収 |
| 12月5日 | 請求 |
| 12月25日 | 支払 |

仮に11月30日の時点で買い手が商品を取得し、債務を認識すべき状態にあるなら、請求書が12月に届いても11月に仕入や棚卸資産、債務を認識する必要があります。一方、契約の実質的な受入条件が12月に満たされるなど、事実関係によっては12月に認識することもあります。

取引を正しい会計期間に帰属させるための考え方を、カットオフ（期間帰属）と呼びます。

月末時点では、納品済み・未検収、受領済み・未請求などの取引を確認し、認識すべき取引の計上漏れや翌月の二重計上を防ぐことが重要です。

## 請求日と支払日は計上日ではない

11月に提供を受けたサービスの請求書が12月に届く場合でも、11月の費用として認識するべき取引なら、金額を合理的に見積もるなどして適切な期間に計上します。

これには、現金の収支とは区別して経済的な事象を認識する発生主義という考え方が関係します。

例えば掛けで商品を10万円購入し、仕入として認識したとします。消費税を省略した簡略例では、次のような仕訳になります。

| 時点 | 借方 | 貸方 |
| --- | --- | --- |
| 仕入計上時 | 仕入 100,000円 | 買掛金 100,000円 |
| 支払時 | 買掛金 100,000円 | 普通預金 100,000円 |

支払時には既に認識した債務を減らします。再び仕入を計上するわけではありません。債権や債務と実際の入金・支払を対応づける処理は消込みと呼ばれます。

消費税についても、原則として課税資産の譲渡等を行った時点などが基準となります。ただし会計と税務の取扱いが常に一致するわけではなく、仕入税額控除の要件なども別途確認する必要があります。

## 日付を管理する目的

購買、物流、品質、契約、会計、支払では、同じ取引を異なる視点で管理します。業務システムでこれらを一つの「取引日」にまとめると、受領実績、検収状況、計上期間、支払期限を区別できなくなる可能性があります。

一方、すべての日付を必ず別々に入力する必要があるわけではありません。取引の種類や管理目的に応じて、必要な記録と根拠資料を決めることが重要です。

## 今日のなるほど

納品日、受領日、検収日、計上日、請求日、支払日は、一つの取引の異なる側面を表しています。

**商品が届いたこと、契約上受け入れたこと、会計上認識したこと、代金を支払ったことは、それぞれ別の事実です。**

日付の意味を理解することで、なぜ経理業務で複数の日付を管理する必要があるのかが見えてきます。
